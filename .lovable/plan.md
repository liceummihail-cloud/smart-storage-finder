## Проблема

Коли користувач диктує речі в кімнату, кожне слово на мить з'являється двічі (наприклад «светр светр»). Після збереження дублі зникають, бо AI-екстракція їх прибирає, але візуально це виглядає як баг.

## Причина

У `src/routes/_authenticated/rooms_.$roomId.tsx`, в обробнику `r.onresult` (рядки 159–166) цикл проходить по всіх нових результатах і додає кожен результат до буфера `txt`. Якщо результат вже фінальний, він **додатково** додається до накопичувача `acc`. У підсумку для одного й того самого фінального шматка показується `acc` (де він уже є) **плюс** `txt` (де він теж є) — звідси «светр светр». На наступному `onresult` `resultIndex` зсувається і дубль зникає.

## Виправлення

Один невеликий правок у `r.onresult`: до буфера інтерим-тексту `txt` додавати лише **не-фінальні** результати, а фінальні — лише в `acc`.

```text
for (let i = e.resultIndex; i < e.results.length; i++) {
  const chunk = e.results[i][0].transcript;
  if (e.results[i].isFinal) {
    acc += chunk + " ";
  } else {
    txt += chunk;
  }
}
setTranscript(acc + txt);
```
