
# Storage Organiser — план MVP

PWA, що допомагає пам'ятати, де яка річ зберігається. Користувач фотографує приміщення, ставить мітки на коробки/шафи, надиктовує вміст, і потім знаходить речі через тап по фото або через розумний пошук.

## Користувацькі сценарії

1. **Реєстрація / вхід** — email+пароль та Google.
2. **Туторіал** (показується одразу після першої реєстрації) — 4 кроки-онбордингу зі свайпом:
   - "Сфотографуй кімнату" (іконка камери)
   - "Тапни по коробці на фото" (анімований пін)
   - "Надиктуй що всередині" (хвиля голосу)
   - "Шукай розумно" (іконка пошуку)
   Кнопки "Далі" / "Пропустити". Прапорець `tutorial_completed` у `profiles` — більше не показується.
3. **Кімнати** — список приміщень. Створення: назва + фото.
4. **Розмітка коробок на фото** — тап ставить пін, можна перетягнути, перейменувати, видалити.
5. **Запис вмісту голосом** — тап на пін → екран коробки → мікрофон. ШІ транскрибує, прибирає слова-паразити, повертає чистий список. Користувач підтверджує/редагує.
6. **Перегляд вмісту** — тап на пін показує список речей.
7. **Пошук** — семантичний (знаходить "куртку" коли записано "пуховик"). Результат: річ + кімната + коробка + кнопка "показати на фото".

## План підписки Freemium

Безкоштовний план із м'якими лімітами, які покривають типового користувача й підштовхують активних до Pro.

**Free (назавжди безкоштовно):**
- до **3 кімнат**
- до **30 коробок** загалом
- до **100 голосових транскрипцій на місяць**
- до **200 семантичних пошуків на місяць**
- стандартна якість фото

**Pro (для майбутнього релізу — у MVP лише показуємо upsell-екран, без оплати):**
- необмежено кімнат, коробок, транскрипцій, пошуків
- шарінг із родиною
- експорт списків

У MVP реалізуємо: enforcement лімітів Free + екран "Upgrade to Pro" із позначкою "Coming soon". Підключення платежів (Stripe/Paddle) — окремим кроком пізніше.

**Реалізація лімітів:**
- Таблиця `usage_counters` (user_id, month, transcriptions_count, searches_count) — інкремент у server function перед викликом ШІ; якщо ліміт перевищено → 402-подібна помилка з тостом і CTA на upgrade.
- Перевірка кількості кімнат/коробок при створенні (server-side).

## Дизайн — Неоморфізм + темна тема

**Філософія:** м'які підняті/вдавлені поверхні на одному фоновому кольорі, два протилежні тіні (світла зверху-зліва, темна знизу-справа), мінімум кордонів, заокруглені кути, плавні переходи.

**Палітра (темна, default і єдина для MVP):**
- `--background`: `oklch(0.22 0.015 260)` — глибокий нейтрально-синій
- `--surface`: те саме що background (неоморфізм вимагає однакового фону)
- `--foreground`: `oklch(0.92 0.01 260)`
- `--muted-foreground`: `oklch(0.65 0.015 260)`
- `--primary`: `oklch(0.7 0.18 280)` — м'який фіолетово-індиго акцент
- `--primary-foreground`: `oklch(0.15 0.01 260)`
- `--accent`: `oklch(0.75 0.15 200)` — холодний м'ятно-блакитний для другорядних акцентів
- `--destructive`: `oklch(0.65 0.2 25)`

**Неоморфні токени (нові):**
- `--shadow-neu-light`: `oklch(0.32 0.015 260)` (підсвітка)
- `--shadow-neu-dark`: `oklch(0.13 0.01 260)` (тінь)
- `--neu-raised`: `-6px -6px 12px var(--shadow-neu-light), 6px 6px 12px var(--shadow-neu-dark)`
- `--neu-pressed` (inset): `inset -4px -4px 8px var(--shadow-neu-light), inset 4px 4px 8px var(--shadow-neu-dark)`
- `--neu-flat-hover`: легша версія raised
- `--radius`: `1.25rem` (м'якіші заокруглення)

**Компоненти:**
- Кастомні варіанти shadcn `Button`, `Card`, `Input` із класами `neu-raised` / `neu-pressed`.
- Активний стан кнопки → `neu-pressed`. Інпути завжди `neu-pressed`.
- Маркери на фото — круглі неоморфні "пігулки" з номером.
- Мікрофон — велика кругла неоморфна кнопка, при записі — pulse + перехід у pressed стан.

Всі тіні й кольори через токени в `src/styles.css`. Жодних inline-кольорів у компонентах.

## Архітектура

**Стек:** TanStack Start (PWA), Tailwind v4, shadcn/ui (з неоморфним рестайлом), Lovable Cloud (Postgres + Storage + Auth), Lovable AI Gateway.

**Таблиці БД (RLS на `user_id`):**
- `profiles` — id, user_id (FK auth.users), display_name, tutorial_completed, plan ('free'|'pro'), created_at
- `rooms` — id, user_id, name, photo_url, created_at
- `containers` — id, room_id, label, x, y (нормалізовані 0–1), created_at
- `items` — id, container_id, name, embedding (vector(768)), created_at
- `usage_counters` — id, user_id, month (date), transcriptions_count, searches_count

Тригер `on_auth_user_created` створює рядок у `profiles` із `tutorial_completed=false`, `plan='free'`.

**Storage bucket:** `room-photos` (приватний, RLS).

**Server functions:**
- `transcribeAudio` — Lovable AI (`google/gemini-2.5-flash` із аудіо), повертає очищений список. Перед викликом інкрементує `usage_counters` і перевіряє ліміт Free.
- `addItems` — зберігає речі + ембедінги (`google/gemini-embedding-001`).
- `semanticSearch` — pgvector cosine search, з лімітом Free.
- `markTutorialDone` — оновлює `profiles.tutorial_completed`.

**Маршрути:**
- `/` лендінг
- `/login`, `/signup`
- `/onboarding` туторіал (редірект сюди після signup, якщо `tutorial_completed=false`)
- `/rooms`, `/rooms/$id`
- `/search`
- `/upgrade` (заглушка Pro)

## Технічні нюанси

- pgvector міграцією.
- Запис аудіо: `MediaRecorder` (webm/opus) → base64 → server fn. На iOS Safari — ініціювати з user gesture.
- PWA manifest + service worker із темною theme_color.
- Стиснення фото клієнтсько (canvas → jpeg, max 1600px).

## MVP не включає

- Реальні платежі (Pro екран — заглушка)
- Категорії/теги, фото окремих предметів
- Шарінг, нагадування, експорт
- Світла тема (тільки темна неоморфна)
- Capacitor-обгортка

## Наступний крок

Після затвердження: увімкну Lovable Cloud → міграції БД + RLS + storage → auth + профілі + тригер → неоморфна дизайн-система в `styles.css` → онбординг-туторіал → екрани кімнат/розмітки/голосу/пошуку → лімітер Free + екран Upgrade.
